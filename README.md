# HEXA Plan Viewer — Windows

Ce dépôt distribue uniquement les installateurs Windows signés et les métadonnées de mise à jour de HEXA Plan Viewer. Le code applicatif et les plans de construction restent privés.

Téléchargez l’installateur dans [Releases](https://github.com/hx-kevincyr/hexa-plan-viewer-releases/releases/latest).

À partir de la version 0.3.0, HEXA vérifie les nouvelles versions au démarrage et propose leur installation. Vous choisissez quand installer. Les signatures sont vérifiées et une copie SQLite locale est créée avant l’installation.

La version 0.2.0 doit être mise à niveau une première fois avec l’installateur. Les mises à jour suivantes sont proposées dans l’application.

La signature de mise à jour HEXA assure l’authenticité de l’installateur téléchargé par le logiciel. Elle est distincte d’un certificat éditeur Windows Authenticode, qui n’est pas encore configuré.
